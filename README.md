# R1 bitstream

## Short description
It is a simple library that allows to encode and decode messages send over the radio for the PW-Sat3 project.

The pipeline consists of three stages (described below in the order of encoding):

### Bit stuffing
In this step after each 5 consecutive ones a zero is inserted.

So for example a stream "111111011111" is converted into "11111010111110".

This allows to avoid passing long streams of ones to NRZI.

### Non-return-to-zero inverted (NRZI)
In this step zeroes are converted into a change in state while ones into lack of change.
The initial state is 1 (high).

The conversion looks as follow:
- "000000" -> "010101"
- "1111" -> "1111"
- "01111" -> "00000"

Combined with bit stuffing this ensures that the stream will be more variable than constant.

### Scrambler
In this step first 12 bits remain unchanged while any other bit is xor-ed with a xor-ed result of bit 12 positions before with result of bit 17 positions before.

For example: "01010101010101010101" is converted into "01010101010100000010".

This means that a clean decoder can start processing from any position and still get correct data after 17 bits.

## Usage examples

### Simple encoding
```rust
use r1_bitstream::pipeline::encode;

fn send() {
	let payload = [0x11u8, 0x22, 0x33, 0x44];
	let stream_to_send = encode(&payload);
	for b in &stream_to_send {
		print!("{b}");
	}
}
```

### Simple decoding
```rust
use r1_bitstream::bitbuf::BitBuffer;
use r1_bitstream::pipeline::decode;

fn receive() {
	let air = BitBuffer::from_bytes(&[0x11, 0x22, 0x33, 0x44]);
	match decode(&air) {
		Ok(data) => {
			for byte in &data {
				print!("{byte}");
			}
		}
		Err(error) => print!("An error occurred: {error}"),
	}
}
```

### Decode with ignoring errors
```rust
use r1_bitstream::bitbuf::BitBuffer;
use r1_bitstream::pipeline::decode_lossy;

fn receive() {
	let air = BitBuffer::from_bytes(&[0x11, 0x22, 0x33, 0x44]);
	for byte in decode_lossy(&air).0 {
		print!("{byte}");
	}
}
```

### Decode with unknown state
Given a bit_buffer with first bit starting from the middle of a message:
```rust
use r1_bitstream::bitbuf::BitBuffer;
use r1_bitstream::biterror::BitError;
use r1_bitstream::pipeline::decode_from_middle;

fn receive(bit_buffer: BitBuffer) {
	let received = decode_from_middle(&bit_buffer);

	match received.1 {
		None => print!("received.0 contains retrived data."),
		Some(error) => match error {
			BitError::NotByteAligned { len } => {
				print!("received.0 contains retrived data.");
				print!("However {} last bits are 0 panned.", 8 - len % 8);
			}
			error => panic!("{error}"),
		},
	};
}
```
